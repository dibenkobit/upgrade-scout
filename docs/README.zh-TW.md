# Upgrade Scout

<img src="logo/logo.png" alt="Upgrade Scout 圖示" width="128" align="right">

**在拍賣場中找出你能用、也買得起的裝備提升和消耗品。** 一款用於《魔獸世界：永恆》（World of Warcraft Forever）的插件。

**在 [CurseForge](https://www.curseforge.com/wow/addons/upgrade-scout) 或 [Wago](https://addons.wago.io/addons/upgrade-scout) 下載**

[English](../README.md) · [简体中文](README.zh-CN.md) · 繁體中文 · [Deutsch](README.de.md) · [Русский](README.ru.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português](README.pt-BR.md) · [한국어](README.ko.md)

打開拍賣場，點擊**裝備提升**分頁，然後按**掃描**。你會得到一份比你身上更好的裝備列表，按部位排列，並標有價格。在想要的裝備上按**購買**即可。

**消耗品**分頁對藥水、藥劑、精煉藥劑、食物、繃帶和油類也做同樣的事。它列出你的角色能使用的消耗品，並給每一件帶來的效果評分。**最適合我的**每種只留一件：對你提升最大的那件，以它的最低價。

在拍賣場之外，任何物品的滑鼠提示也會顯示它比你身上的裝備好多少：背包、拾取視窗、任務獎勵和聊天連結裡都能看到。

## 功能

- 掃描只顯示你現在能裝備、也買得起的裝備。
- **消耗品**分頁列出你能使用的藥水、藥劑、精煉藥劑、食物、繃帶和油類，對你的角色最有用的排在前面。對你沒用的不會顯示。
- 在每個部位標出兩件裝備。**最大提升**是最強的那件。**最划算**是每點提升花費最少的那件。
- **淨花費**顯示一件物品最終花掉你多少：直購價減去用完後賣給商人的價錢。4銀幣買入，3銀幣賣出，實際花了1銀幣。
- **預算內的最佳組合**會選出一組提升：用你全部的金幣，或你輸入的金額，合起來提升最多。
- **篩選**選單用來縮小列表。**只看皮甲**、**只看鎖甲**或**只看鎧甲**會去掉比你的角色所穿最重護甲更輕的護甲。**提升至少**會去掉提升低於你所填百分比的裝備。
- 也能為你的其他角色購物。郵箱處的按鈕會把買到的裝備放進寄給他們的信裡。
- 任何物品的滑鼠提示都會按你職業的每個天賦系顯示它比你身上的裝備好多少，例如戰士的武器、狂怒和防護。在插件視窗裡可以只留一行（你在用的那一系），也可以選擇這些行顯示在哪裡：插件的拍賣場分頁、遊戲裡的其他地方，或者都不顯示。
- 背包或銀行裡物品圖示上的綠色箭頭表示它是你現在就能裝備的提升。灰色箭頭表示等級夠了就能裝備的提升。
- 安裝後即可使用。**方案**下拉列表一開始選的就是你天賦點最多的那一系。
- 第一次登入時會彈出一個視窗，說明插件做些什麼。在那裡可以關掉物品提示裡的行和背包裡的箭頭。點小地圖旁的插件按鈕可再次打開。
- 用自己的屬性權重給裝備評分，每個天賦系各有一套，由 [wowsims/forever](https://github.com/wowsims/forever) 模擬器算出。不需要其他插件。
- 在用 Pawn？在插件視窗裡選擇 **Pawn**，裝備就依你的 Pawn 權重評分，而不是依插件內建的權重。列表和背包裡的箭頭都以它為準，物品提示裡的行則由 Pawn 自己來寫。

支援所有職業和等級。支援英語、簡體中文、繁體中文、德語、俄語、法語、西班牙語、巴西葡萄牙語和韓語。

## 安裝

**透過 [CurseForge](https://www.curseforge.com/wow/addons/upgrade-scout) 或 [Wago](https://addons.wago.io/addons/upgrade-scout) 安裝**

CurseForge 或 Wago 應用程式會幫你裝好一切。

你需要《魔獸世界：永恆》（World of Warcraft Forever，1.60.1），不需要其他插件。

手動安裝：

1. 從 [CurseForge](https://www.curseforge.com/wow/addons/upgrade-scout)、[Wago](https://addons.wago.io/addons/upgrade-scout) 或 [GitHub 發布頁](https://github.com/dibenkobit/upgrade-scout/releases)下載 `UpgradeScout-<版本>-forever.zip`。
2. 解壓縮到 `World of Warcraft\_forever_\Interface\AddOns`。
3. 重新啟動遊戲。

## 須知

- 物品的評分是它各項屬性乘以方案中對應權重之和。方案在**方案**下拉列表中選擇，一開始選的是你天賦點最多的那一系，你可以改選別的。
- 權重是按60級角色計算的，所以只是近似值。60級以下，命中、致命一擊、加速和熟練的價值會打折扣，這是按練級角色模擬得出的。
- 耐力（坦克除外），以及治療者的智力、精神和法力恢復，是手動設定的：傷害模擬無法衡量生存或法力耗盡的代價。
- 護甲、格擋值、防禦、閃躲和招架在每個方案中都會計入：相對於耐力，按它們對模擬器中坦克的作用計算。
- 方案名稱後面的 `~` 表示這個天賦系還沒有模擬，權重是估算的。
- 價格都是直購價。只能競標的拍賣會被跳過。
- 勾選**淨花費**後，價格一欄和**最划算**都按淨花費來算。買不買得起和**預算內的最佳組合**仍按直購價來算：那才是你要付的錢。
- **每個部位前5件**讓列表保持簡短。關閉它可以看到所有提升，但掃描會更久，在繁忙的拍賣場裡可能要幾分鐘。
- **提升**一欄用百分比表示這件裝備比它要取代的那件好多少。**新增**表示該部位是空的。顯示分數（如 `+6 分`）表示你在那裡穿的裝備對你的方案毫無用處。
- **只看皮甲**裡寫的是你的角色已經學會穿的最重的護甲：獵人是皮甲，學會鎖甲後就是鎖甲。披風、戒指、武器和盾牌仍留在列表裡。法師、牧師和術士只穿布甲，沒有這個勾選框。
- **提升至少**按**提升**一欄裡的百分比來算。空部位的裝備始終保留。
- 每個角色各有自己的**只看皮甲**勾選和**提升至少**數值。為其他角色購物時，看到和修改的是那個角色的設定。
- 名稱後面的黃色 `*` 表示這件裝備有評分沒有算進去的效果。
- 生命藥水和法力藥水沒有評分：沒有哪個權重能給「恢復700點生命力」算分。
- 「猛虎之」靴子和「巨鯨之」靴子是不同的物品，價格也不同。遊戲的「賣出」分頁把它們放在同一個列表裡，所以那裡的最低價可能是另一件物品的。

## 為其他角色購買

1. 在裝了插件的情況下登入一次另一個角色。插件會記下它的裝備、等級和技能。
2. 用站在拍賣場的角色，在**方案**下拉列表中選擇另一個角色的方案，然後按**掃描**。

現在列表是為那個角色產生的。付錢的仍然是你正在玩的角色。

在郵箱處把買到的裝備從信件中取出。信件視窗下方的按鈕會把它們放進一封寄給那個角色的信裡。檢查一下信，然後按**發送**。消耗品需要你自己寄。

插件記住的是你上次玩那個角色時的狀態。它升級或換了裝備之後，請再登入一次。

## 指令

- `/upscout` 打開插件的視窗：它做些什麼，以及它的設定。在拍賣場則打開「裝備提升」分頁。
- `/upscout stats` 顯示上次掃描用了多久。
- `/upscout stats` 加上一件物品（按住Shift點擊物品，把它放進聊天輸入框）會列出這件物品的每項屬性、它在方案中的權重以及合計。
- `/upscout forget 名字` 把已刪除的角色從列表中移除。
